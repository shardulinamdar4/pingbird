Setup (about 5 minutes)

Before you start

  1. Get a free OpenRouter API key (openrouter.ai → Keys).
  2. Install Pocket Alert on your phone and create one webhook whose Message Template is exactly %message%. Copy the receive URL.

Marketplace install

  1. Install Pingbird from the Google Workspace Marketplace.
  2. Open any Google Sheet (a fresh blank one is perfect) → Extensions → Pingbird → 🚀 Quick setup.
  3. Approve the Google permissions, then paste your OpenRouter key and Pocket Alert URL when asked. Quick setup builds the whole template (Home, Tracker, Settings), sends one test AI request and one test phone ping, and installs the five daily scans (6 AM, 10 AM, 2 PM, 6 PM, 10 PM).
  4. Run Scan now for your first scan, then Run backfill batch to import history (default 6 months; the first run asks).

Manual install (open source)

Prefer to run from source? Create a blank Google Sheet → Extensions → Apps Script → paste Code.gs and appsscript.json from the GitHub repo → run Quick setup. Full walkthrough in the repo's guides/SETUP_GUIDE.md.

Daily use

Do nothing. When something needs you, the email stays unread in your Inbox with an Action required label and your phone gets one ping. Mark items Completed right from the Home screen's attention list — the Tracker, labels, and archive state sync automatically.
