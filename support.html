Frequently asked questions

The AI test fails / Settings shows a "Last AI error". The default model openrouter/auto needs OpenRouter credits. On a free account, use Extensions → Pingbird → Advanced → Set AI model and enter a free model such as meta-llama/llama-3.3-70b-instruct:free — the dialog tests it immediately. When AI is unavailable, Pingbird falls back to safe rule-based decisions; nothing is archived without rule-level proof.

My phone alert shows raw JSON or nothing. In Pocket Alert, the webhook's Message Template must be exactly %message%.

Noise rows appeared in the Tracker. Run Advanced → Dismiss noise Review rows once, then update to the latest Code.gs — newer versions filter platform notifications, tax/bank lookalikes, and newsletters before they reach the Tracker.

How do I import old email? Run backfill batch. It walks your chosen window (default 6 months, up to 24) in 15-day slices, newest first, and tells you exactly which dates were imported and where the next run resumes. Backfilled history never triggers phone alerts.

Is my email safe? Yes — by architecture. No server, no account; everything runs inside your Google account, and only sanitized excerpts reach the AI provider you configured yourself. Full map: Privacy Policy.

How do I uninstall completely? Extensions menu → manage add-ons → uninstall (or delete the script), delete the spreadsheet, remove the three Gmail labels, and revoke access at myaccount.google.com/permissions.

Diagnostics

Open the Settings sheet: it shows last scan time, last scan error, last AI error, alert delivery status, and backfill progress. Every scan also writes stage-by-stage PERF timings to the hidden _Log sheet — include these when reporting an issue.
